Installing Sync it

  1. If Chrome says the file might be harmful, tap Download anyway. Sync it is safe; it's only new to Google's scanner.
  2. When it finishes, tap Open. No button? Open Chrome's menu ⋮ → Downloads and tap sync-it.apk.
  3. If Android asks, allow Chrome to install apps (Allow from this source), go back, then tap Install.
Stuck at 2.7 MB / 2.7 MB with a pause icon? Chrome hasn't finished checking the file.
